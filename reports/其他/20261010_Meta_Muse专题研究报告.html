一、产品全景：Muse 是什么

定义：Muse 是 Meta 于 2026 年 9 月推出的个人 AI Agent——用户说出目标，Muse 拆解任务、打开网页、填写表单、调用外部应用，可收发邮件、安排日程、预订旅行、比价购物、电话砍价、出售汽车等，并在用户关闭应用后继续后台执行。底层由 Muse Spark 1.3 模型驱动，已进入 Meta AI、WhatsApp、Instagram、Facebook。

三、商业化路径：免费获客 → 订阅 → 交易抽成

  • 定价结构：免费层每周 1 亿 token（覆盖绝大多数日常任务）；重度用户订阅 $20/月（5 亿 token）、$100/月（30 亿 token）两档。
  • 长期变现：交易抽成 + 智能体广告竞价（专家称）。华创转述 Connect 口径：通过从促成交易中收取小额费用实现盈利；现阶段愿意承担亏损换用户。
  • 战略转向（专家交流要点）：Meta 正由 Llama 开源生态转向闭源模型商业化，MUSE 采用独立于 Llama 的训练体系，聚焦 AI 购物及任务型 Agent。
  • 转化率证据：整合 IG/FB 授权用户数据做个性化推荐，相关场景转化率较传统算法提升至少约 30%；采用「传统算法初筛 + 大模型二次精排」兼顾效果与成本。
  • 场景落地难度：机票、酒店等标准化场景易落地；服装等隐性偏好品类难度高。瓶颈在第三方数据接入与复杂任务执行——亚马逊已限制访问，部分航司 API 未开放影响推荐完整性。

token 消耗分层（专家口径）：纯聊天 <1 万；工具调用 1 万~20 万；Computer Use 类最高可达 100 万；95% 以上用户主要使用轻度聊天功能——意味着收入弹性短期靠订阅、长期靠把重度场景做起来。

来源：浑水调研Plus 2026-10-09（Meta MUSE 专家交流纪要）、短评&信息 09-10、09-24（华创）、09-25

对 Meta 自身：广告平台 → 交易入口

多家观点：Agent 能直接识别「用户正在买什么、预约什么、取消什么」，商业信号从「兴趣」升级为「真实交易意图」，变现模式有望从广告展示延伸至交易佣金、Agent 服务与商业分润。富国银行（转述）因 Muse Spark 表现将 Meta 目标价由 640 美元上调 24.5% 至 796 美元（维持增持；2026-09-18 股价 665.75 美元，上行空间 19.6%）。另有观点测算：Meta 26 年中性预测广告业务利润超 1000 亿美元，给予 20-30×PE，至少看到 2 万亿美元以上市值空间。

来源：短评&信息 09-21（富国转述）、09-22（事件点评）；浑水调研Plus 09-21（路演反馈）

四、算力重估：从「GPU 推理」到「GPU + CPU + 云执行」

产业逻辑：传统大模型算力集中于 GPU 推理；Muse 为每用户配置持久化云端虚拟机（无头浏览器 + 高频 API 调用 + 多步任务编排），单次行程比价最多发起 146 次网页搜索，任务在用户退出后仍持续占用 CPU。卖方普遍引用的判断：AI 服务器 CPU/GPU 配比将由约 1:4~1:8 向 1:1~1:2 演进，CPU 量价齐升——Intel 管理层称只能满足约 50% 的 CPU 需求，Intel/AMD 先后推动涨价（台积电代工价拟上调约 10%，AMD 计划 26Q4 上调约 10%，Intel 传 10 月再上调 PC CPU 约 10%）。

左图：中金科技硬件转述的 9 月下旬（截至 9/27 当周）Muse 反馈催化下单周涨幅——CPU/互联/存储板块领涨，北美对 Muse 的热度显著高于亚洲。右图：星球内流传的 1 亿 DAU 情景测算（取区间中值作图）。

反面测算：CPU 需求叙事可能被高估

  • 1 亿 DAU ≠ 1 亿台并发 VM：假设日均 Agent 工作 2 小时 + 峰值均值比 2.5× + 20% 冗余 ≈ 需预置约 2500 万台活跃 VM（约 25% DAU 同时在线）。
  • VM 大量时间处于等待态、CPU 可激进超配：按每活跃 VM 0.5 物理核估算 ≈ 1250 万物理核 ≈ 5~6.5 万颗 CPU，硬件价值不足 10 亿美元；DRAM 约 75-100PB，约 20 亿美元——「比许多人预期的要小」。
  • 沙盒层仅需约 0.1 GW；模型推理才是真瓶颈（每次重度推理事件约 5-10 Wh，人均 50 次/天 → 推理需 1-2 GW），总需求 3-4 GW 完全合理——与传闻 Meta 明年增加 7-10 GW 算力相互印证。
  • 结论：消费者 Agent 是 CPU 与传统 DRAM「有意义的新需求驱动」，但把逻辑 VM 分配当专用物理基础设施是根本性错误；推理需求增速可能远快于用户数本身。

卖方圆桌：涨后的分歧（9/24）

  • AMD：乐观于 CPU 影响（已预期同比 +70% 以上），但近期涨幅多由估值倍数扩张驱动（买方预期 2028 EPS 30 美元 × 20×PE → 1 万亿美元市值），开始抵触估值。
  • Intel：CPU 利好已定价，代工业务（Foundry）才是进一步重估的关键，投资者处于「建设性 vs 观望」分裂状态。
  • ARM：更多受益于估值重估与「Muse 赢家组合」纳入，短期非基本面驱动。
  • 存储双向争论：看多者认为较 CPU 更被低估（2028 年前供给收紧）；看空者质疑 Agent 并非真 24 小时运行、LTA 锁价限制短期上行；MU（9/30 财报）11 月季度 EPS 指引预期 38-40 美元。

五、平台博弈与竞争格局：「封杀 vs 接入」的流量战争

亚马逊封杀（9/20）——四点理由具有行业标杆意义

未提前告知 / Agent 未自我标识 / 捕获并存储客户凭证 / 可触及账户页面与订单历史。实质指向数据安全、身份认证与商业利益分配三大矛盾。

伯恩斯坦（10/8）：稳态不是封杀，而是「选择性展示 + 权限 API + 数据定价」

  • 消费 AI Agent 的长期成功必须从「拟人浏览」转向「授权 API 接入」；沃尔玛、百思买、丝芙兰、Ulta、Gap、Wayfair 及全量 Shopify 目录已宣布建立连接器——但 OpenAI Instant Checkout 的前车之鉴说明合作推进复杂度被低估。
  • Cloudflare 数据：互联网非人类流量首次过半，其网络 AI Agent 日均请求量一年暴增 1700%；高爬取品类人类流量不到一年暴跌 40%。
  • 新增摩擦点：Agent 流量额外验证与「人机协同」检查点；客服系统将 Agent 呼叫路由至独立队列；大型银行（参照摩根大通对数据聚合商收费）可能对 Agent 数据拉取反向收费。
  • 核心投资结论：支付产业链是确定性赢家——交易频次提升 + 100% 令牌化 + 复杂度溢价，利好 Visa（目标价 450 美元）、万事达（710 美元）、Adyen、PayPal、Affirm；建议超配支付板块。
  • 蓝海判断：低渗透品类（健康美容、生鲜杂货、汽车零部件）与服务场景（跨平台活动协调、旅行规划——美国旅客预订前平均浏览 277 页、耗时约 5 小时）价值大于高渗透零售品类。

竞品动态

  • OpenAI：9/29 发布个人 Agent「dots」；此前 Instant Checkout 曾集结沃尔玛、Etsy、Instacart 及超百万 Shopify 商户。
  • 谷歌：Gemini Spark（7×24 个人 Agent，跨 Workspace 主动管理工作流）+ Daily Brief，悄然构建代理生态，分发优势显著。
  • Instinct：约 40% 用户 3 周内绑定信用卡，年化交易额已达约 10 亿美元（约 50% 来自旅行），但核心用户偏富裕技术前卫群体。

六、风险与分歧（多方观点汇编）

  • 留存是最大问号：好评多来自「一次性存量收割」（错误扣款、可议价账单、被遗忘订阅），挖完就没有了；可持续高频场景偏少，需要找到让用户每周回来的理由。
  • 商家反制：亚马逊已封杀；AI 砍价普及后，保险、宽带商家可能拒接 AI 来电、收紧议价空间；接电话的客服并不知道对面是 AI。
  • 切换成本低：已有用户几天内把 OpenClaw 配置和 Claude 多智能体工作流迁到 Muse——反向迁移同样容易；真正难复制的只有 Meta 生态里的用户上下文。
  • 算力叙事高估风险：CPU 沙盒层硬件价值测算显著低于市场直觉（<10 亿美元 CPU / 约 20 亿美元 DRAM @1 亿 DAU）；AMD/Intel 涨幅已含较大估值扩张成分。
  • 商业化未验证：交易抽佣尚未实质落地；大规模落地数据、平台爬虫权限博弈、隐私与监管仍是核心变量。
  • Meta 自身：2026Q3 计提 100 亿美元法律和解相关支出（富国转述），2026 年运营利润预期下调 12%。
来源：短评&信息 09-23（Muse&ConsumerAI 产业更新）、09-28（测算帖）、09-21（富国转述）；浑水调研Plus 09-24（圆桌）

七、国内映射：入口封闭，更可能走「平台原生 Agent」

核心差异：美国线上需求分散在网页端、支付跨商户通用，Muse 可通过云端浏览器统一完成任务；中国超级 App 把数据、交易、权限留在各自生态里——豆包手机跨 App 操作曾被微信、淘宝相继限制，二代仅接入曹操出行等少数第三方。且国内移动基建完善（改套餐、退订阅点几下就完成），本来就没有多少摩擦可以抹平，Muse 模式难以照搬。东方通信观点更直白：「Web 时代欠在 Mobile 的账，变成了 Agent 时代的资产」；Muse 干了 Apple 想干没干成的事；超级 APP 将迭代成或让位于超级 Agent。
