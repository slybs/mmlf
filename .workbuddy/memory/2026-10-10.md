## 记录存储迁移到 mmlf 本地文件（16:55）
- 用户要求：记录数据放到 mmlf 目录里，不要只在 localStorage。
- 方案：数据文件 `data/notes.js`（`window.NOTES = [...]`，与 reports.js 同款 script 加载方式，file:// 协议下 fetch 不可用所以必须用 JS 而非 JSON）；写入用 Chrome/Edge 的 **File System Access API**（showSaveFilePicker + createWritable），句柄存 IndexedDB（`mlf-notes-fs` 库 `handles` 表）实现"连接一次以后自动读写"，每次打开页面 queryPermission 自动恢复。
- 数据流：内存 = merge(localStorage, window.NOTES)（id 并集，同 id 取 updatedAt 新）；persist 时同步写 localStorage（缓存）+ 文件（若已连接），并把 window.NOTES 更新为最新防旧数据复活；load 时若一边为空直接取另一边。
- 不支持 FSA 的浏览器（Safari/Firefox）自动退回 localStorage，状态栏提示；「导出备份」保留。
- notes.html 加 `<script src="data/notes.js">`（在 js/notes.js 之前）；about.html 的记录功能章节与目录树同步重写。
- 逻辑冒烟测试通过（mergeLists 并集 / 取新 / 空不覆盖 / notes.js 正则解析）。
